# update-contract

Read the agreement first. Show the requested fields and update only those. Activating requires signed evidence and core fields. Recording terminated is bookkeeping after the responsible person confirms the event; it sends no notice.

Run: node scripts/contracts.mjs update-contract with the required arguments below. Add --json for structured results.

--contract --actor with changed fields, including --status

Use the CLI output as the source. On ambiguity, present all candidates and resolve the record before retrying. Errors are not permission to substitute another record. Nothing sends, signs, pays or deletes.
