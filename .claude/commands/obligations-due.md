# obligations-due

Include outstanding duties on ended agreements. Identify the owner and completion evidence needed for each overdue promise.

Run: node scripts/contracts.mjs obligations-due with the required arguments below. Add --json for structured results.

Open deliverables, including terminated agreements: --days=14

Use the CLI output as the source. On ambiguity, present all candidates and resolve the record before retrying. Errors are not permission to substitute another record. Nothing sends, signs, pays or deletes.
