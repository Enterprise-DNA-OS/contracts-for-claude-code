# activity

Read the operator-recorded history. Actor names are supplied text, not authenticated signatures.

Run: node scripts/contracts.mjs activity with the required arguments below. Add --json for structured results.

Operator-recorded history: optional --contract

Use the CLI output as the source. On ambiguity, present all candidates and resolve the record before retrying. Errors are not permission to substitute another record. Nothing sends, signs, pays or deletes.
