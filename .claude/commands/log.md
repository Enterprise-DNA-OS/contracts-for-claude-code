# log

Record the operator, actual event and factual note. Do not invent communication or acceptance.

Run: node scripts/contracts.mjs log with the required arguments below. Add --json for structured results.

--contract --note --actor

Use the CLI output as the source. On ambiguity, present all candidates and resolve the record before retrying. Errors are not permission to substitute another record. Nothing sends, signs, pays or deletes.
