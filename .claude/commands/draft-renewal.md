# draft-renewal

Read the full agreement. Generate an internal decision brief in drafts/. Check the text against evidence. It is not a notice and must never be sent as one.

Run: node scripts/contracts.mjs draft-renewal with the required arguments below. Add --json for structured results.

--contract; writes an internal decision brief to drafts/

Use the CLI output as the source. On ambiguity, present all candidates and resolve the record before retrying. Errors are not permission to substitute another record. Nothing sends, signs, pays or deletes.
