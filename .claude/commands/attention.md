# attention

Prioritise late notice dates, overdue duties and missed reminders. Then name unassigned agreements and those quiet for over fourteen days.

Run: node scripts/contracts.mjs attention with the required arguments below. Add --json for structured results.

Late deadlines, overdue work, missing owners and quiet agreements

Use the CLI output as the source. On ambiguity, present all candidates and resolve the record before retrying. Errors are not permission to substitute another record. Nothing sends, signs, pays or deletes.
